Sii 隐私政策（中文）

最后更新：2026-11-02

一、总则
Sii 不设账号体系，不收集你的个人信息，不内置统计、广告或崩溃上传 SDK。所有数据默认保存在本机应用私有目录。

二、本地保存的数据
1. 书签、历史记录、常用网站、下载记录、脚本、站点设置：保存在应用私有数据库。
2. 密码库：密码使用 Android Keystore 生成的 AES-256-GCM 密钥加密后保存，密钥不出设备；明文只在需要填充或查看时于内存中解密。
3. 缓存与 Cookie：由系统 WebView 保存在应用私有目录。
4. 无痕模式：不写入浏览历史；退出无痕时是否清理 Cookie、缓存、下载文件与翻译缓存由你的设置决定。

三、权限与用途
1. 相机：仅在你主动使用扫码功能时使用，用于识别二维码。
2. 通知：下载进度、MCP 服务运行状态。
3. 安装未知应用：仅用于安装你在 Sii 中下载的 APK，安装前会显示应用名称、版本与包名供你确认。
4. 网络与网络状态：加载网页、检查更新、下载文件。

四、会联网的场景
1. 打开网页：直接连接网站。
2. 检查更新：访问 GitHub API（api.github.com），会向 GitHub 暴露你的 IP 地址。
3. 翻译：把你选择的文本或网页内容发送给你在设置中选择的翻译服务商；本地翻译不联网。
4. 应用内 DoH：把域名解析请求发送给你选择的 DoH 服务商（阿里、腾讯、Cloudflare 或 Google）。
5. 规则订阅、站点图标、脚本更新：访问对应地址以下载规则、图标或脚本。
6. MCP 服务：默认关闭，仅在局域网或本机监听，内容由你选择连接的客户端读取。

五、数据删除
1. 可在「设置 → 隐私与安全 → 清除数据」中清理缓存、Cookie、历史等。
2. 卸载软件会删除应用私有目录内的全部数据。
3. 密码库支持导出 CSV 与清空；导出的 CSV 为明文，请自行妥善保管。

六、儿童
本软件不面向儿童设计，也不收集儿童个人信息。

七、变更与联系
本政策可能随功能变化更新，更新后的内容会在软件内展示。问题反馈：QQ 群 1128056947。
